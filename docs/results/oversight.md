## Why the fallback rate is what it is

Every draft, the agency's included, replayed a committed Claude recording (the owner in this run is a recorded demo persona), passed the validator and went to a person; none fell back. The agency's department-head plans fell back to the rule order because a plan recording replays only for the exact candidate list it was recorded on (the recorded cohort is a different one). With the network off nothing else can happen; with it on, the other reasons (`validation_failed:*`, provider errors, budget) appear, and `GET /metrics/abstention` reports them by reason, language and channel in the same shape.
