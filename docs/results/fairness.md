# Fairness audit (M7-5)

Generated by `tools/rai/fairness.py` (`make rai-fairness`; `make rai-fairness-check` fails if this file differs from a fresh run). Do not edit by hand.

**All data are synthetic.** The triage replies are developer-written templates, the risk-score cohort is simulated and the red-team set is self-authored. These numbers show how the shipped models and rules behave on those sets, split by language. They are not evidence about real patients. No native Arabic speaker and no clinician has reviewed the data yet (H1, H2).

## What this does not show

- Performance on real patients' replies, real dialect spread (Emirati, Levantine, Egyptian, South Asian English) or real Arabizi spelling.
- Intersectional groups (for example Arabizi on WhatsApp, or age by language) for the risk score.
- Whether the Arabic templates read naturally: that is the native-speaker review (H2), not a metric.
