# Test cases

Every ticket in [TRACKER.md](TRACKER.md) lists the test cases that must pass before it is `done`. IDs are `T-<cut><number>`. Status `existing` means the test is already in the repo and passing at M0; `planned` means the owning ticket writes it.

Types: unit, property (Hypothesis or equivalent, many generated inputs), integration (needs Postgres and sometimes HAPI), e2e (browser), load, chaos (fault injection), manual (a person does it and records the result).
